# Env Contract v0.1.2

Maintenance release draft, 2026-11-06 (Asia/Shanghai).

- Preserve U+2028/U+2029 inside single-quoted, double-quoted and unquoted values.
  They remain data and do not increment LF/CRLF source line numbers. Previously,
  valid assignments containing those characters were rejected.
- Include the README's linked docs, contributor guidance and synthetic examples
  in the installable tarball. Run both packaged quickstart examples after an
  offline installation; valid input passes and invalid input retains exit 2.
- Keep CLI options, existing limits, value-free reports and JSON schema 1.

The new parser and installed-example regressions failed before the fixes.
Local tests, strict build, static runtime checks, offline package verification
and a clean-install quickstart are required. Three-platform hosted CI must pass
at the release commit before this draft is created.

```sh
npm install --global ./env-contract-cli-0.1.2.tgz --ignore-scripts
```

No npm publication. The bundled dotenv examples are synthetic; reports still
expose variable names and line numbers and require review before sharing.
