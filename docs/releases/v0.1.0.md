# Env Contract v0.1.0

Initial release draft, 2026-10-31 (Asia/Shanghai).

- Generate required string contracts from example variable names, without copying values.
- Validate explicit dotenv inputs against types, ranges, lengths, choices and URL protocols.
- Export value-free Markdown/JSON/standalone HTML, with bounded input and CI thresholds.

Requires Node.js 22+. Install the attached tarball locally:

```sh
npm install --global ./env-contract-cli-0.1.0.tgz --ignore-scripts
envcontract --help
```

Unit/CLI tests, strict build, static checks, offline package installation and
three-platform hosted CI are required. No npm registry publication is performed.
Reports still expose names and line numbers; review them before sharing.
