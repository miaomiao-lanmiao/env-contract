# Env Contract v0.1.1

Maintenance release draft, 2026-11-01 (Asia/Shanghai).

- Reject duplicate JSON properties at every object level, including escaped
  spellings of an earlier key. Repeated keys in different objects remain valid.
- Bound JSON nesting to 128 levels and preserve sanitized parsing errors.
- Keep existing CLI options, dotenv semantics and JSON report schema 1.

The duplicate-key CLI regression reproduced silent acceptance before the fix.
All 60 local tests, strict build, static checks and offline installed-package
verification pass. Three-platform hosted CI is required before this draft.

```sh
npm install --global ./env-contract-cli-0.1.1.tgz --ignore-scripts
```

No npm publication or real user configuration access is performed. Reports still
expose variable names and line numbers and require review before sharing.
